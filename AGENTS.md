## Navigation

A folder groups conventions. A file other than `index.md` is one convention.

Open a folder's `index.md` before its other files. The index summarizes the folder and lists each contained file and folder in a table with the columns `path` and `content`.

`README.md` maps a task to the convention that decides it.
